# Portal web — Conocimiento Integral y de Emergencia

## Archivos
- `index.html`: estructura del sitio y botones de contacto.
- `styles.css`: diseño, botones de contacto y adaptación responsive.
- `script.js`: contenido e interacción de las seis tarjetas (sin cambios de funcionalidad).
- `Logo_VG_color.png`: logotipo institucional utilizado en el encabezado.

## Contactos agregados

## Probar localmente
Abre la carpeta en Visual Studio Code y ejecuta `index.html` con Live Server.

## Publicar en GitHub Pages
Sube los cuatro archivos a la raíz del repositorio y activa GitHub Pages desde `Settings > Pages`.

Los botones de correo abren la aplicación de correo predeterminada mediante `mailto:`. LinkedIn y YouTube se abren en una pestaña nueva.
